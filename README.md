# DG Portfolyo

Kişisel portfolyo web sitem.

Frontend geliştirme alanındaki çalışmalarımı, kendimi ve geliştirdiğim projeleri sergilemek amacıyla hazırlanmıştır.

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript
* React
* Responsive Design

## ✨ Özellikler

* Responsive tasarım
* Modern ve sade arayüz
* Hakkımda bölümü
* Yetenekler bölümü
* Projeler bölümü
* İletişim formu
* CV indirme
* GitHub ve LinkedIn bağlantıları
* Mobil uyumlu hamburger menü

## 📱 Responsive

Web sitesi farklı ekran boyutlarına uyum sağlayacak şekilde geliştirilmiştir.
